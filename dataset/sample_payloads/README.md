This folder contains the benign synthetic payload files used for the LSB steganography experiments.

Payloads are organised by file type and size class: small, medium, and large. These files were used only to generate controlled stego-images and to evaluate file-type attribution.

The EXE payloads are harmless test binaries used solely for signature-based attribution experiments. They are not malware.
